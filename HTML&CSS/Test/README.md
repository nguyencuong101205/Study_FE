# Backgrund

- background-color Đặt màu nền cho phần tử.

Tên màu (red), HEX (#ff0000), RGB/RGBA (rgba(0,0,0,0.5)), HSL.

- background-image Đặt hình ảnh hoặc gradient làm nền.

url('image.jpg'), linear-gradient(...), radial-gradient(...).

- background-repeat Xác định hình nền có lặp lại khi không phủ kín hay không.

repeat (mặc định), no-repeat, repeat-x, repeat-y, space, round.

- background-position Xác định vị trí xuất phát của hình nền.

center, top left, bottom right, hoặc tọa độ 50% 50%, 10px 20px.

- background-size Điều chỉnh kích thước hiển thị của hình nền.

cover (phủ kín), contain (vừa khung), auto, hoặc kích thước cụ thể 100% auto, 200px 150px.

- background-attachment Xác định ảnh nền cố định hay cuộn theo trang.

scroll (cuộn theo trang - mặc định), fixed (cố định khi cuộn), local (cuộn theo nội dung phần tử).

- background-origin Xác định vùng bắt đầu vẽ ảnh nền (tính từ viền, padding hay nội dung).

border-box, padding-box (mặc định), content-box.

- background-clip Cắt vùng hiển thị nền (chỉ cho phép nền hiện ở đâu).

border-box (mặc định), padding-box, content-box, text (tạo chữ màu nền).

- background-blend-mode Tạo hiệu ứng hòa trộn giữa các lớp ảnh nền hoặc giữa ảnh và màu nền.

multiply, screen, overlay, darken, lighten, color-dodge,...
