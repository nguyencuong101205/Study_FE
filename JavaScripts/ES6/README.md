# Học JavaScript ES6 (ECMAScript 2015)

Thư mục này chứa tài liệu tổng hợp toàn diện các tính năng mới trong **ES6 (ECMAScript 2015)** dựa trên chuẩn tài liệu của [W3Schools JavaScript ES6](https://www.w3schools.com/js/js_es6.asp).

## Danh mục tài liệu

- 📄 [Tài liệu chi tiết các tính năng mới trong ES6 (ES6_Features.md)](./ES6_Features.md)

### Nội dung bao gồm:

1. **Khai báo biến:** `let` và `const` (Block Scope, Temporal Dead Zone, so sánh với `var`).
2. **Hàm mũi tên (Arrow Functions):** Cú pháp, lexical `this`.
3. **Destructuring Assignment:** Object & Array Destructuring.
4. **Toán tử Spread (`...`) & Rest Parameter:** Trải mảng/đối tượng và tham số còn lại của hàm.
5. **Vòng lặp `for...of`:** Duyệt mảng, chuỗi và các iterable object.
6. **Cấu trúc dữ liệu mới:** `Map` và `Set`.
7. **Hướng đối tượng (Classes):** `class`, `constructor`, `extends`, `super`.
8. **Xử lý bất đồng bộ:** `Promise` (`resolve`, `reject`, `.then()`, `.catch()`).
9. **Kiểu dữ liệu nguyên thủy mới:** `Symbol`.
10. **Tham số mặc định (Default Parameters).**
11. **Template Literals:** Chuỗi nhúng biến `${}` và chuỗi nhiều dòng.
12. **Phương thức chuỗi mới:** `.includes()`, `.startsWith()`, `.endsWith()`.
13. **Phương thức mảng mới:** `Array.from()`, `Array.keys()`, `Array.entries()`, `Array.find()`, `Array.findIndex()`.
14. **JavaScript Modules:** `import` và `export`.
15. **Proxy & Reflect:** Can thiệp và tùy chỉnh thao tác trên object.
16. **Phương thức đối tượng:** `Object.assign()`.
17. **Cải tiến Number & Math:** `Math.trunc()`, `Math.sign()`, `Number.isInteger()`, `Number.EPSILON`, v.v.
18. **RegExp Flags:** Cờ Unicode `/u` và Sticky `/y`.
